# 常见排错记录（脱敏版）

这些是项目开发过程中遇到的典型问题，示例不含任何真实 Key。

## 在 Python 提示符中输入 PowerShell 语法

**现象：** 输入 `$env:OPENAI_API_KEY` 或 `if (...) { ... }` 后出现 `SyntaxError`。

**原因：** `>>>` 是 Python 交互提示符；`$env:` 和花括号命令是 PowerShell 语法。

**处理：** 先用 `exit()` 回到 `PS ...>`，再执行 PowerShell 命令。环境变量检查也应在 PowerShell 中进行，不要把 Key 值复制到聊天或截图。

## 相对路径找不到脚本或虚拟环境

**现象：** PowerShell 报告 `..venv\Scripts\python.exe` 或脚本不存在。

**原因：** 相对路径是从当前目录解析的。提示符若仍显示 `PS C:\Users\...>`，说明尚未进入项目文件夹。

**处理：** 从仓库根目录运行 `cd .\commute-assistant`；然后运行 `Get-Location` 确认路径末尾是 `commute-assistant`。也可在命令中使用完整路径。

## PowerShell 阻止激活虚拟环境脚本

**现象：** 执行 `Activate.ps1` 时显示因执行策略而禁止脚本。

**原因：** 当前 PowerShell 执行策略阻止运行激活脚本。

**处理：** 不必更改系统执行策略；直接使用虚拟环境解释器，例如 `& .\.venv\Scripts\python.exe .\commute_web.py --demo`。

## Key 检查成功但程序没有读取到

**现象：** 程序仍提示没有设置 Key，或地图服务返回 Key/权限错误。

**排查顺序：** 确认 Key 是在启动程序的同一个 PowerShell 窗口设置的；确认变量名正确（`AMAP_WEB_KEY` 对应高德，`OPENAI_API_KEY` 对应 OpenAI）；再确认平台上的 Key 类型、服务权限和额度。不要打印或发送 Key 本身。离线演示 `--demo` 不需要任何 Key。

## 定时任务报告不在预期目录

**现象：** 手动运行能生成文件，但固定时间没有看到新报告。

**排查顺序：** 电脑需在计划时间开机、用户已登录；查看 `commute_logs` 的运行记录和任务状态；报告应保存在项目的 `commute_reports`。计划任务写入文件夹，不会自动发送邮件或推送通知。

## 路线或天气服务不可用

**现象：** 页面提示服务不可用，或报告只含部分信息。

**处理：** 先看错误属于哪项服务，再核对网络、Key 权限、请求参数和服务额度。部分服务失败时，项目会尽量保留其他已成功数据；没有路线时不应把空结果解释成“附近无路线”。将错误详情分享给协助者前，先检查并遮盖 Key、个人地址、坐标和本机用户名。

## 未来时间没有历史估算

**现象：** 显示符合条件的日期不足。

**原因：** 估算依赖这台电脑本地保存的同路线历史地图预计值；当前门槛为至少三个不同日期。换电脑、清理数据库或路线几何改变都会减少可匹配样本。

**说明：** 这是历史样本估算，不是预测模型或未来实时路况。不要为了凑样本而频繁发送无意义请求；如果该功能没有实际帮助，可以先不使用。
